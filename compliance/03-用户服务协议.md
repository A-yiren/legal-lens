## 二、服务内容

2.1 律瞳 LegalLens 是一款**基于检索增强生成（RAG）技术**的法律智能分析工具，提供以下功能：

| 功能 | 描述 |
|------|------|
| 案件分析 | 基于用户输入案情，检索 26 部中国现行法律 + 30 个类案种子，给出参考分析 |
| 类案检索 | 从类案库召回相似真实判例 |
| 合同审查 | 基于规则引擎 + RAG + LLM 识别合同风险点和缺失条款 |
| 知识库浏览 | 26 部法律全文 + 官方源跳转 |

2.2 **本服务当前为免费公共服务**，未来如调整收费规则将提前 30 日公示。

## 三、用户行为规范

3.1 您承诺不在本服务中输入、上传或传播以下内容：
- （1）违反中华人民共和国法律法规的内容
- （2）涉及国家秘密、工作秘密、商业秘密、个人隐私的内容
- （3）您无权处理的他人案件信息（除非您是当事人或经授权代理人）
- （4）淫秽、暴力、恐怖、赌博等违法不良信息

3.2 您理解并同意：
- 您的输入内容将**仅用于当次服务响应**，不会用于训练任何 AI 模型
- 我们不会主动存储您的案情描述
- 但基于网络通信的固有特性，输入内容可能在传输过程中经过 LLM 服务提供方
