### 2.3 数据合法性

**核心法律依据**：

1. **法律法规不享有著作权**：
   - 通行国际著作权法原则（如《伯尔尼公约》第 2 条）
   - 中国《著作权法》第五条："法律、法规、国家机关的决议、决定、命令和其他具有立法、行政、司法性质的文件，**官方正式译文不享有著作权**"
   - 因此，26 部法律文本属于**公有领域**，可自由使用

2. **公开渠道采集**：
   - 国家法律法规数据库（flk.npc.gov.cn）由全国人大常委会维护，**官方公开发布**
   - 各部委官方网站公开发布的法律法规文本

3. **元数据附加**：
   - 每条法条携带官方源 URL，方便用户一键跳转原文核实
   - 不修改原文内容
   - 不歪曲原意

### 2.4 数据结构

每条法律在系统中包含以下字段：

| 字段 | 含义 | 示例 |
|------|------|------|
| `doc_id` | 文档唯一 ID | `doc-2b21d391fe85` |
| `law_name` | 法律全称 | `中华人民共和国劳动合同法` |
| `article_no` | 条款号 | `第十二条` |
| `article_text` | 条款全文 | `固定期限劳动合同...` |
| `source_url` | 官方源 URL | `https://flk.npc.gov.cn/...` |
| `publisher` | 发布机关 | `全国人民代表大会常务委员会` |
| `law_status` | 当前状态 | `现行` / `已修订` / `废止` |
| `decree` | 令号 | `中华人民共和国主席令第七十三号` |
| `effective_date` | 施行日期 | `2008-01-01` |
| `chunk_index` | 块索引 | 0, 1, 2... |
| `text` | 向量化文本 | 完整内容 |

### 2.5 质量控制

| 维度 | 控制方式 |
|------|----------|
| 原文准确性 | 人工抽样核对 5% 文本 |
| 元数据准确性 | 自动从源页面解析 + 人工复核 |
| 状态时效性 | 标记"现行/已修订/废止"，提示用户核实 |
| 抓取失败 | 跳过并日志告警，不入库不完整文本 |

### 2.6 已知问题

1. ⚠️ **解析过程中曾混入网页版权说明**（如"投诉/举报 免责声明"等），已通过 Qdrant 关键词过滤脚本清理
2. ⚠️ **法律更新同步滞后**：当前知识库为 2026 年 6 月采集，2026 年 6 月后的修订可能未及时更新
3. ⚠️ **司法解释未全部收录**：本服务仅收录 26 部法律主文本，未收录最高法司法解释（如《关于审理民间借贷案件适用法律若干问题的规定》等）

### 3.3 数据真实性声明

**关键声明：本服务的 30 个类案判例的"案号、法院、案由、引用法条"为真实公开信息；案情细节经过改写以脱敏，不构成对原判决的复制。**

| 字段 | 来源 | 真实性 |
|------|------|--------|
| 案号 | 公开判决文书 | ✅ 真实格式（部分细节改写） |
| 法院 | 公开判决文书 | ✅ 真实 |
| 案由 | 公开判决文书 | ✅ 真实 |
| 引用法条 | 公开判决文书 | ✅ 真实 |
| 当事人姓名 | 公开判决文书 | ⚠️ 部分改写为化名 |
| 案情细节 | 公开判决文书 | ⚠️ 改写脱敏 |
| 判决结果 | 公开判决文书 | ⚠️ 改写 |

### 3.4 数据合法性

1. **案号、法院、引用法条属事实信息**，不受著作权法保护
2. **司法判例的"判决书全文"**在 2021 年后部分文书不再公开（中国裁判文书网），已公开部分属于可公开访问
3. **本服务不复制原判决全文**，仅保留结构化要素
4. **不替代中国裁判文书网**：本服务用户如需核实，应自行到 https://wenshu.court.gov.cn/ 查询

## 四、用户输入数据

### 4.1 严格不收集

| 数据类型 | 状态 |
|----------|------|
| 案情描述 | **不持久化** |
| 合同全文 | **不持久化** |
| 当事人姓名 / 联系方式 | **不存储**（仅当次处理） |
| IP + 行为 | HTTP 日志（30 天滚动） |

### 4.2 临时处理原则

用户输入数据严格遵循以下原则：

1. **最小化**：仅处理您主动输入的内容
2. **不存储**：处理完成后从内存清除
3. **不训练**：不用于训练任何 AI 模型
4. **不分析**：不分析您的输入用于画像
5. **不外传**：除调用 LLM API 外不传输任何第三方

详见 [04-隐私政策.md](./04-隐私政策.md)。
