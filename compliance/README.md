## 🎯 律瞳的产品定性

**核心定位**：基于 RAG（检索增强生成）技术的法律知识检索与分析工具

**关键技术栈**：
- **大语言模型**：MiniMax-Text-01（API 调用，不自训）
- **向量检索**：Qdrant（嵌入式部署）
- **知识库**：26 部中国现行法律（含官方源 URL / 发布机关 / 施行日期）
- **判例库**：30 个真实案号格式的类案种子

**关键边界**（重要！影响备案路径）：
- ✅ **检索**：从自有知识库召回
- ✅ **引用**：每条观点带 `[n] 法名 第X条` 引用，可点跳转原文
- ❌ **不训练模型**：不收集用户数据训练 LLM
- ❌ **不做内容生成训练数据**：用户输入案情仅用于当次回答
- ❌ **不直接代理诉讼**：不替代律师出庭

**备案路径**：
1. 走"具有舆论属性或社会动员能力的互联网信息服务"算法备案（生成式 AI 类目）
2. ICP 备案（已有）
3. 公安网安备案（视情）
4. 不需要"深度合成"专项备案（不涉及人脸生成、合成语音等）

## 📊 评估要点

律瞳需关注的合规风险：

| 风险类别 | 律瞳具体情况 | 缓解措施 |
|----------|--------------|----------|
| **内容安全** | LLM 可能生成错误法律意见 | A3 引用校验 Agent 逐字核对 + 免责声明 + 多 Agent 协同 |
| **幻觉** | LLM 虚构法条 / 案号 | A3 幻觉标记 + 自动剔除 + 引用强制跳原文 |
| **数据来源** | 26 部法律来自公开官方源 | 数据来源说明 + 官方 URL 标注 |
| **用户隐私** | 案情可能含敏感当事人信息 | 不持久化案情、不训练、传输加密 |
| **专业责任** | 律师误用 AI 后果严重 | 顶部显著免责声明 + 不替代专业律师声明 |
| **未成年人** | 是否需要限制 | 建议加年龄限制声明 |

## 🚀 使用建议

1. **先填写实际信息**：本文档是模板，需要把 `[xxx]` 替换为你的真实数据
2. **找专业律师审一遍**：备案材料是法律文件，建议请律师过目
3. **公示版精简**：用户看到的版本要短，备案提交的版本可以详细
4. **持续更新**：算法或数据源变更时同步更新评估报告
