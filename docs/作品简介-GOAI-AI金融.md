# 金睛 RiskLens — 金融法律风险研判 AI 助手

> **赛道**：GOAI 2026 Boundless Agents · AI+金融
> **Demo**：https://ayiren.cn/legallens/（demo / demo123）
> **仓库**：https://github.com/A-yiren/legal-lens

## 项目

**金睛 RiskLens** 是面向律师/法务/合规的金融法律 Agent，把"查法条 → 找类案 → 研判风险 → 出下一步"四步串成 60 秒出报告的可运行闭环。

## 行业场景（25%）

银行客户经理、保险公司理赔、理财经理、信贷审批员面对法规查询慢、类案检索难、风险研判散、可溯源缺失四大痛点，金融场景出错代价高。

## Agent 能力与闭环（25%）

**4 Agent 协同**：A1 案情理解 → A2 法规检索（BGE RAG 1840 chunks）→ A3 类案匹配（60 判例）→ A4 风险研判。**7 步闭环**：输入 → 意图 → 规划 → 调用 → 交付 → 验证 → 安全。**鲁棒三因子置信度**：基础 0.60 + 引用 0.20 + 焦点 0.15 + 论证 0.04，上限 0.99。

## 产品与 Demo（20%）

Web 5 屏 + Mobile 5 屏 + 游客登录 + 2:40 视频；4 验收样本（虚构/网购/劳动/三焦点）全通过。

## 技术实现（15%）

MiniMax-Text-01 + BGE 中文 Embedding + Qdrant 本地 + SQLite + FastAPI + Nginx，部署阿里云 ECS（1.6GB 内存可跑）。

## 安全合规（10%）

6 份合规文件；**不替代律师/风控最终判断**；60 判例全来自公开裁判文书网无敏感信息。

## 开放复用（5%）

41 法规 + 60 判例数据集（MIT）+ 完整代码（GitHub 公开）+ DEPLOY.md 一键部署 + Mobile UI 模板可复用。

**数据**：41 法规 · 60 判例 · 2020 向量块 · 4 Agent · 7 步闭环
