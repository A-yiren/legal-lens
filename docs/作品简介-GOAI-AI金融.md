## 一、行业场景价值

金融行业 70% 以上的日常业务咨询与法律风险研判强相关。银行客户经理审核房贷/信用卡纠纷、保险公司理赔岗评估保险责任、理财经理审查理财适当性、信贷审批员判断授信风险——这些岗位每天要面对同一组问题：法条是什么、有没有类似判例、本案风险点在哪里、下一步该做什么。

但现实困境是：
- **法规查询慢**：商业银行法、保险法、证券法、信托法等 41 部核心法律 + 数百个司法解释，翻查耗时
- **类案检索难**：30 真实判例分散在中国裁判文书网、内部知识库、Excel 表格中，找不到过往判例就只能说"建议咨询律师"
- **风险研判散**：法条 + 类案 + 客户情况需要人工拼接，错漏率与时效性都无法保证
- **可溯源缺失**：大模型生成的"看似合理"答案无法标注来源，金融场景出错的代价不可承受

**金睛 RiskLens** 把"查法条 → 找类案 → 研判风险 → 出下一步"四步串成可运行、可演示、可复用的 Agent 闭环，**真实嵌入到银行/保险/理财/风控等岗位的日常决策流**。

## 二、Agent 能力与任务闭环

系统采用**多 Agent 协同架构**，不同职能 Agent 各司其职：

| Agent | 角色 | 工具 | 输出 |
|---|---|---|---|
| **A1 案情理解 Agent** | 解析案情关键事实、识别案由、提取当事人/金额/争议焦点 | LLM + 规则引擎 | 结构化案件画像 |
| **A2 法规检索 Agent** | 匹配适用法律、定位具体条款 | RAG（BGE-small-zh-v1.5，1840 chunks） | 候选法条 Top-5 + 相似度 |
| **A3 类案匹配 Agent** | 检索历史判例、计算相似度 | RAG（60 真实判例 180 chunks） | 相似判例 Top-3 + 引用条文 |
| **A4 风险研判 Agent** | 整合法条 + 类案 + 案情，输出研判结论与下一步建议 | LLM + CoT 推理 | 5 字段结构化报告（case_focus / legal_analysis / risks / next_steps / citations） |

**完整任务闭环**（覆盖大赛要求的 8 个环节）：

1. **任务输入**：用户在"案件分析"页粘贴案情描述
2. **任务拆解**：A1 拆出案由、金额、当事人、争议焦点
3. **上下文传递**：A1 结果 → A2 → A3 → A4，每步压缩关键事实
4. **工具调用**：A2/A3 调 RAG，A4 调 LLM（MiniMax-Text-01），合同审查走规则引擎
5. **结果验证**：每条结论自动引用对应法条/判例（`citations` 字段）
6. **执行证据沉淀**：分析结果落到 SQLite + 入参到案件库（用户可追溯）
7. **审批与回滚**：用户在案件库可编辑/删除案件，PUT/DELETE 端点直接生效
8. **经验沉淀**：用户新建案件可基于历史分析模板快速复用

## 三、产品体验与 Demo 完成度

**已上线公共 Demo**：https://ayiren.cn/legallens/

5 大核心页面，4 Agent 流程一气呵成：

- **AI 分析**：案情输入 → 一键生成结构化分析报告

**端到端验证 9/9 通过**（2026-08-13 实测）：健康检查、6 项 REST CRUD、4 Agent 流程、3 类金融场景检索命中、引用溯源显示、登录注册、跨页面状态。

## 四、技术实现深度与工程可复现性

**技术栈**（全部开源可复现）：
- 后端：Python 3.12 + FastAPI 0.115 + SQLAlchemy + Pydantic v2
- 向量库：Qdrant（embedded local mode，单进程部署）
- Embedding：BAAI/bge-small-zh-v1.5（512 维，本地推理）
- LLM：MiniMax-Text-01（OpenAI 兼容接口）
- 前端：原生 HTML + Tailwind CDN + Font Awesome（无构建步骤）

**核心数据资产**（41 部法规 + 60 判例 全部公开可下载）：
- **41 部法律**：26 部通用（民法典/刑法/民诉/刑诉/公司法/劳动法/知识产权/消费者保护）+ **15 部金融核心**（商业银行法/证券法/期货和衍生品法/证券投资基金法/信托法/反洗钱法/票据法/个人金融信息保护试行办法/征信业管理条例/商业银行理财业务监督管理办法/外汇管理条例/银行业监督管理法/存款保险条例/银行卡业务管理办法/民间借贷司法解释）
- **60 真实判例**：30 法律 + **30 金融**（金融借款/信用卡盗刷/内幕交易/保险代位/期货强行平仓/票据追索/融资租赁/征信/私募基金等）

**工程亮点**：
- **双 RAG 隔离**：法规 vs 案例走两个 Qdrant collection + 独立 payload `category` 字段
- **检索增强溯源**：每个法条/判例都带 `citations` 字段链接回原文片段
- **可观测**：所有检索返回 score + chunk_id，调试可追溯

## 五、安全、合规与开放复用价值

**数据合规**：
- 全本地部署，案件数据不出企业内网
- 用户认证复用 aipath JWT，账号隔离
- 案件库 CRUD 强制带 user_id 过滤（多租户隔离）

**行业应用边界**（明确写入 UI）：
- 不替代律师/合规官/法官的最终决策
- 输出含"建议咨询专业人士"提示
- 金融风险研判**仅作为辅助参考**

**开源价值**：
- 核心代码可开源（MIT）
