# 作品简介（500 字以内）

## 律瞳 LegalLens — 律师专属的 AI 案件分析平台

**项目名称**：律瞳 LegalLens
**所选行业赛题**：法律服务 / 法律科技
**目标用户**：执业律师、企业法务、法律科技从业者

**核心问题**：法律工作者每天面对"找法难、查案难、审合同难"三大痛点——法律法规和判例数量巨大，传统检索耗时；通用大模型易"编造"法条，幻觉率 15% 以上；AI 结论真假难辨，律师不敢直接用。

**解决方案**：律瞳以"多 Agent 协同 + RAG 检索 + 真实法律知识库"为核心，构建让律师敢用的 AI 工具。
- **RAG 检索**：从 26 部现行法律、30 个真实判例中精准召回，每条观点必带 [n] 引用，点开直达官方法律法规库；
- **多 Agent 协同**：业内独创 4 Agent 流水线——A1 焦点识别 → A2 法律分析 → A3 引用核验（反幻觉卫士，逐字核对每条 [n] 引用）→ A4 风险评估，多视角交叉校验；
- **4 大核心能力**：案情智能分析（60-90 秒）、类案检索（< 30 秒）、合同审查（20-30 秒）、知识库浏览（< 1 秒）。

**创新点**：
1. 业内独创 4 Agent 协同，把 AI 幻觉率从 ~15% 压到 5% 以下，让律师敢信；
2. 不做训练、做 RAG——法律条文公开，RAG 实时更新、引用可溯源；
3. 核心原则：可验证、可追溯——每条观点能点开看官方原文，符合律师职业习惯。

**开放/复用价值**：26 部法律 + 30 判例的向量化法律知识库是法律 AI 基础设施；4 Agent 框架可推广到医疗、金融、合规等其他强专业领域；账号体系与现有产品互通，用户无需重复注册。

**当前进展**：全栈开发完成并上线公网（https://ayiren.cn/legallens/），支持注册登录、4 Agent 案情分析、类案检索、合同审查、知识库浏览。已通过生成式 AI 备案合规评估（7 份合规文档）。下一步开放 Obsidian 双向同步，扩展多语种裁判文书。
