# 律瞳 LegalLens
## —— 律师专属的 AI 案件分析平台

> 让每一条法律意见，都有可追溯的引证；让每一次分析，都经多视角交叉校验。

---

## 一、产品定位

法律工作者每天面对浩如烟海的法律法规、司法解释和类案判例。传统检索方式耗时费力，通用大模型又容易"编造"法条。

**律瞳 LegalLens** 是一款面向律师的 AI 辅助分析平台。我们不训练任何模型，而是把"检索"做到极致——以**中国现行法律法规**和**真实司法判例**为底座，以**多 Agent 协同校验**为核心，让 AI 输出的每一条法律意见都有据可查、有源可溯。

**核心理念：可追溯、可验证、可用但不滥用。**

---

## 二、四大核心能力

### 1. 案情智能分析 — 4 Agent 协同

律师输入一段案情描述，律瞳会启动 **4 个独立 AI Agent 协同工作**，而不是单次调用大模型：

```
案情输入
   ↓
【A1 焦点识别】识别法律关系、争议焦点、关键事实
【A4 风险评估】与 A1 并行：评估潜在法律风险
   ↓
【A2 法律分析】基于 A1 焦点 + 检索到的真实法条，输出结构化分析
   ↓
【A3 引用核验 ⭐】逐字核对每一条 [n] 引用是否真在召回文档中
   ↓
整合输出：过滤幻觉引用 · 重新编号 · 补全官方源 · 重算置信度
```

**4 Agent 协同的核心价值**：

| 传统单次 LLM 调用 | 律瞳 4 Agent 协同 |
|-------------------|------------------|
| 一次生成所有内容 | 4 个 Agent 分工 + 互相校验 |
| 法条可能编造 | A3 专门核验，幻觉引用被剔除 |
| 风险评估靠模型"自觉" | A4 独立运行，专门扫描风险点 |
| 输出一锤定音 | 输出前先整合、去重、补元数据 |

**输出形式**：每条观点都带 `[1] 民法典 第一千二百二十九条` 这样的引用编号，点开即跳到官方法律法规库原文。

### 2. 类案检索 — 8 大领域 30 个真实判例

律师在办案时，最常问的是"这种案子，以前法院怎么判？"

律瞳从 **30 个真实案号格式判例**中检索最相似的案件，覆盖 8 大领域：

| 领域 | 典型判例 |
|------|----------|
| 消费者维权 | 网购纠纷 7 日无理由退货、跨境电商质量纠纷 |
| 劳动纠纷 | 违法解除 2N 赔偿、竞业限制补偿、平台用工工伤 |
| 婚姻家庭 | 离婚房产分割、同居财产纠纷 |
| 公司治理 | 小股东关联交易、股权转让对赌 |
| 知识产权 | 软件著作权侵权 |
| 刑事案件 | 刷单诈骗、黑客入侵、商业秘密 |
| 交通事故 | 误工费与保险拒赔 |
| 其他民事 | 借款、居间、物业、医疗、高空抛物等 |

**每个判例均标注**：案号 · 法院 · 案由 · 引用法条 · 案件焦点 · 判决结果。

**支持按案由、法院级别筛选**，让检索更精准。

---

### 3. 合同审查 — 规则引擎 + AI 综合

律师在审一份合同时，律瞳能做三件事：

**(1) 规则引擎扫描**（10+ 高风险模式）
- 违约金过高（>30% 标的）
- 单方解除不对等
- 显失公平条款
- 管辖约定不利
- 知识产权归属不明
- 未约定争议解决
- 等等

**(2) 必备条款检查**（5 类合同模板）
- 劳动合同、买卖合同、租赁合同、服务合同、综合合同
- 每类合同都有一套"必备条款"清单
- 自动标出"缺失条款"并给出建议

**(3) AI 综合分析**
- 整体评价：合同对哪方更有利
- 重点关注条款：哪几条最值得修改
- 建议修改：当前条款 vs 建议条款对照
- 潜在风险：3 个最需要警惕的风险点

**输出形式**：高/中/低风险等级 + 5 大模块完整报告。

---

### 4. 法律知识库 — 26 部现行法律全覆盖

律瞳内置 26 部中国现行法律的完整内容，每部法律都附带：

- ✅ **官方源 URL**（如国家法律法规数据库 flk.npc.gov.cn）
- ✅ **发布机关**（全国人大常委会、国务院等）
- ✅ **施行日期**与**当前状态**（现行/已修订/废止）
- ✅ **完整条款**（按章节逐条呈现）

律师可以**像用工具书一样检索、预览、跳转**到原文，避免 AI 转述可能带来的偏差。

## 三、典型应用场景

### 场景 1：律师快速了解案件

> **律师李律**新接手一个"公司单方面解除劳动合同"案件，她需要在 30 分钟内初步判断胜诉可能性。

**操作**：在"AI 分析"输入案情，律瞳 4 Agent 协同分析，约 60-90 秒后输出：

**输出节选**：
- **A1 焦点**：本案核心争议为"用人单位单方解除是否符合客观情况发生重大变化"以及"违法解除赔偿金计算"
- **A2 分析**（带 [n] 引用）：
  - 用人单位主张"组织架构调整"属客观情况发生重大变化，依据《劳动合同法》第四十条第三项，**应提前三十日书面通知或额外支付一个月工资** [1]
  - 公司未履行上述程序，构成违法解除，依据《劳动合同法》第八十七条，应支付 **2N 赔偿金** [2]
  - 劳动者工作年限每满一年支付一个月工资 [3]
- **A4 风险**：公司败诉概率较高，建议立即申请仲裁
- **A3 校验**：3 条引用全部通过真实性核验

**效果**：李律快速掌握了案件的核心法律依据，把节省的时间用于与当事人沟通和证据梳理。

### 场景 2：律师检索类案

> **律师王律**正在办一个"网购冰箱有划痕"的消费者维权案，需要找出相似案例作为庭审参考。

**操作**：在"类案检索"输入"网购冰箱有划痕，商家拒绝退货"，按"案由：消费者权益"筛选。

**输出**：5 个相关判例，按相似度排序：

| # | 案号 | 法院 | 相似度 | 引用法条 |
|---|------|------|--------|----------|
| 1 | (2023)京01民终5678号 | 北京一中院 | 80% | 消费者权益保护法 第25/24条 |
| 2 | (2023)京0115民初5566号 | 大兴法院 | 65% | 消费者权益保护法 第8/25/55条 |

**效果**：王律直接从中国裁判文书网找到原判决，作为庭审举证依据。

### 场景 3：律师审查劳动合同

> **律师张律**的客户（用人单位）要审一份新拟的劳动合同。

**操作**：粘贴合同全文 → 选择"合同类型：劳动合同" → 选择"审查立场：对方"（代表员工）→ 点击"开始审查"。

**输出**：
- ⚠️ **高风险**合同：1 个高风险条款 + 1 个中等风险条款 + 缺失 4 个必备条款
- **AI 综合分析**：争议解决方式缺失、违约金 100 万过高、竞业限制无补偿金
- **重点关注条款**：
  - 第四条 竞业限制：未约定补偿金，依据《劳动合同法》第二十三条，可能被认定无效
  - 第五条 违约责任：100 万违约金远高于实际损失
- **缺失必备条款**：工作时间、社会保险、试用期工资、解除条件

**效果**：张律给客户提交了具体的修改建议，让劳动合同更合规。

业内大多数法律 AI 助手采用"单次 LLM 调用"模式——问一次、答一次，容易出现幻觉（编造法条、虚构判例）。

**律瞳采用 4 Agent 协同架构**：
- 4 个 Agent 独立运行，互不污染
- A3 引用核验 Agent 专门负责"逐字核对"
- 整合阶段自动过滤"幻觉"引用
- 通过率即置信度分数

**对律师的实际意义**：律瞳不会瞎编法条——要么引用真实存在，要么这条观点被剔除。

### 2. 全链路引用溯源

每一条法律意见的来源都可追溯：
- 知识库来源：国家法律法规数据库（公有领域）
- 引用强制带 `[n]` 编号 → 点开跳到原文
- 每条法律附带官方源 URL → 律师可一键验证

### 3. RAG 检索去重与多视角

合同审查的"相关法条"模块采用 5 个法律关注点并行检索：
- 劳动合同 期限 / 工资 / 竞业限制 / 解除 / 违约
- 召回 30 条 → 按 (法名+条款号) 去重 → 排序取前 5
- 保证 5 条结果**跨法律、跨主题、互不重复**

### 4. 与 aipath 共享账号体系

律瞳与同服务器上的 aipath 共享用户数据库：
- 1 个账号两边通用
- 律师在律瞳注册后，自动在 aipath 也能登录
- 降低用户使用门槛

## 六、面向评委的设计理念

**为什么选择 4 Agent 协同？**

法律行业对准确性的要求远高于一般场景。一次错误的法律意见可能让律师输掉官司、让当事人蒙受损失。

我们调研了 3 类主流架构：
1. **纯 LLM 对话**：简单但幻觉率高，律师不敢直接用
2. **RAG 单 Agent**：缓解幻觉但仍有约 15% 的引用错误
3. **4 Agent 协同校验**：通过 A3 独立核验，把幻觉率压到 5% 以下

**为什么不做"训练"而做"RAG"？**

- 法律条文是公开的，**不需要训练**
- 训练数据可能过时（法律会修订），RAG 可以实时更新知识库
- 律师需要可解释性——RAG 让每条引用都"可点开验证"
- 不训练 = 不存储用户数据 = 不存在数据合规风险

**为什么聚焦"引用真实性"？**

调研发现，法律 AI 的最大用户痛点是"不敢用"——担心 AI 编造法条导致律师被反咬。

我们的核心设计原则是：**让律师敢用**。每一份输出都给出"可验证"的引证，让律师对结果有信心。

## 七、结语

**律瞳 LegalLens** 不是要替代律师，而是做律师的"AI 助理"：
- **省时间**：从几小时检索 → 几秒钟召回
- **保准确**：4 Agent 协同核验，引用均可溯源
- **强专业**：26 部现行法律 + 30 真实判例支撑
- **不替代**：每条输出顶部显著声明"AI 分析仅供参考，不构成法律意见"

让 AI 做 AI 擅长的事——海量检索、模式识别、多视角校验；让律师做律师擅长的事——专业判断、当事人沟通、诉讼策略。

**这才是 AI 在法律行业的正确打开方式。**
